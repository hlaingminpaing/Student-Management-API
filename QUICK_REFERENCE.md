# Quick Reference - Cognito Implementation\n\n## What Changed?\n\n### Frontend Updates\n✅ Authentication modal (login/signup)\n✅ Session management with JWT tokens\n✅ Protected API calls with Authorization header\n✅ Logout functionality\n✅ Automatic token validation\n\n### Files Modified\n- `frontend/index.html` - Added auth UI\n- `frontend/script.js` - Complete rewrite with Cognito integration\n- `frontend/style.css` - Added auth styling\n\n---\n\n## Quick Setup (5 Minutes)\n\n### 1. Update Script Config\n\nEdit `frontend/script.js` lines 4-7:\n\n```javascript\nconst COGNITO_CONFIG = {\n    region: 'ap-southeast-1',              // Your region\n    userPoolId: 'YOUR_POOL_ID',            // From AWS Cognito\n    clientId: 'YOUR_CLIENT_ID',            // From AWS Cognito\n};\n```\n\n### 2. Get Your Credentials from AWS\n\n**Region**: What region is your User Pool in?\n- Example: `us-east-1`, `eu-west-1`, `ap-southeast-1`\n\n**User Pool ID**:\n1. Open AWS Console → Cognito\n2. Select your User Pool\n3. Go to \"General settings\"\n4. Copy \"Pool ID\" (format: `region_xxxxx`)\n\n**Client ID**:\n1. Go to \"App integration\" → \"App clients and analytics\"\n2. Click your App Client\n3. Copy \"Client ID\"\n\n### 3. Enable Password Auth in Cognito\n\n1. Cognito → Your User Pool\n2. \"App integration\" → \"App clients and analytics\"\n3. Click your app → Edit\n4. Under \"Authentication flows\":\n   - ✅ Check \"ALLOW_USER_PASSWORD_AUTH\"\n   - ✅ Check \"ALLOW_REFRESH_TOKEN_AUTH\"\n5. Save\n\n---\n\n## Testing Locally\n\n```bash\ncd frontend\npython -m http.server 8000\n# Open: http://localhost:8000\n```\n\n### Test Scenarios\n\n1. **Sign Up**: Create new account (verify email in AWS Console)\n2. **Login**: Enter credentials\n3. **CRUD Operations**: Create/Read/Update/Delete students\n4. **Logout**: Click Logout button\n5. **Verify**: Refresh page - should still be logged in (session persists)\n\n---\n\n## API Gateway Integration\n\n### For Each Endpoint (GET/POST/PUT/DELETE):\n\n1. **Select method** in API Gateway\n2. Click **Method Request**\n3. Under **Authorization**, click pencil\n4. Select **CognitoAuthorizer**\n5. Click checkmark\n6. **Deploy API**\n\n### Enable CORS\n\n1. Select `/students` resource\n2. Click **Actions** → **Enable CORS**\n3. Add headers: `Content-Type, Authorization, X-Amz-Date, X-Api-Key`\n4. Deploy API\n\n---\n\n## Frontend Architecture\n\n```\n┌─────────────────┐\n│  User Opens App │\n└────────┬────────┘\n         │\n         ▼\n┌──────────────────────┐\n│ Check LocalStorage   │\n│ for testing)\nawait performLogin('user@example.com', 'Password123');\n\n// Check if logged in\nconsole.log(currentUser);      // Shows: user@example.com\nconsole.log(idToken);          // Shows: JWT token\n```\n\n### Make API Call with Token\n\n```javascript\n// Automatically includes authorization header\n$.ajax({\n    url: 'https://api.example.com/students',\n    type: 'GET',\n    headers: getAuthHeaders(),  // Adds: Authorization: Bearer {token}\n    success: function(data) {\n        console.log(data);\n    }\n});\n```\n\n### Check Token Claims\n\n```javascript\n// Decode JWT to see user info\nconst parts = idToken.split('.');\nconst payload = JSON.parse(atob(parts[1]));\nconsole.log(payload);\n// Shows: { sub, email, name, exp, etc. }\n```\n\n---\n\n## Cognito Password Requirements\n\nDefault policy (enforced by Cognito):\n- ✅ Minimum 8 characters\n- ✅ At least 1 uppercase letter (A-Z)\n- ✅ At least 1 lowercase letter (a-z)\n- ✅ At least 1 number (0-9)\n- ✅ Special characters optional\n\n**Example valid password**: `MyPassword123`\n\n---\n\n## Error Messages & Fixes\n\n| Error | Fix |\n|-------|-----|\n| \"Blank modal / Nothing loads\" | Check browser console, verify Cognito config in script.js |\n| \"Invalid client id\" | Copy correct Client ID from Cognito App Client settings |\n| \"USER_PASSWORD_AUTH not enabled\" | Enable in App Client → Authentication Flows |\n| \"Password did not conform\" | Use: 8+ chars, 1 uppercase, 1 digit |\n| \"API returns 401\" | Token expired - user needs to login again |\n| \"Email already exists\" | That email is already registered |\n| \"Network error\" | Check internet, verify AWS region, check CORS |\n\n---\n\n## Important Files\n\n```\nstudent-management-api/\n├── frontend/\n│   ├── index.html          ← COGNITO_CONFIG is correct\n\n### \"Sign up email verification not received\"\n- Check spam folder\n- Cognito may be in Sandbox mode - request production access\n- Verify email address is correct\n\n### \"App not showing after login\"\n- Check localStorage: `localStorage.getItem('idToken')`\n- Check browser console for JavaScript errors\n- Clear localStorage: `localStorage.clear()` and try again\n\n### \"API calls failing with 401\"\n- Token may be expired (1 hour limit)\n- Login again\n- Check Authorization header format: `Bearer {token}`\n\n---\n\n## Next Advanced Features
